# Mission: Codex 长程 Agent 的源码级理解与工程复用

## Why

学习目标来自真实长任务中的可观察变化：子 Agent 规划更稳、任务状态可恢复、预算边界附近会出现状态跃迁。课程要把这些现象还原成可审计的模型、Harness、持久状态与验证机制，使后续设计和调试能够依赖证据。

## Success looks like

- 能区分长上下文、长程执行、可恢复性与跨任务 Memory。
- 能把 Sol、`max`、Ultra、Multi-agent、Goal、rollout、compaction 和项目 Artifact 放入正确层级。
- 能从官方资料与当前源码定位一项 Codex 行为，并标注事实、推断、未知与版本边界。
- 能设计一个具备目标持久化、并发约束、恢复检查点、证据化完成和安全停止条件的长程 Agent Harness。
- 能把稳定结论沉淀为可复用参考资料，并在源码漂移后重新核验。

## Constraints

- 课程使用中文，保留关键英文源码术语。
- 每课只解决一个紧凑问题，控制在 10–15 分钟，并包含即时反馈与延迟检索入口。
- 官方资料和源码是主要证据；研究报告、课程和记忆材料均保留快照日期与 commit 边界。
- 未经学习者练习证明的内容不写入 `learning-records/`。

## Out of scope

- 猜测未公开的模型参数、MoE 路由、完整训练配方或 Ultra 私有调度器。
- 把单项 benchmark 分数解释成某个组件的独立因果贡献。
- 在第一阶段展开全部 Rust 实现细节；源码深挖将在心智模型稳定后分机制进行。
